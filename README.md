🎓 ClassHub – Academic Assignment & Deadline Manager

📌 Overview

ClassHub is a classroom application designed to help students manage assignments, tests, quizzes, and all academic deadlines in one centralized platform.
The system improves organization, reduces missed deadlines, and provides clear visibility into upcoming and completed work.

🎯 Problem Statement

Students often receive assignments and test information through multiple channels such as email, LMS platforms, and in-class announcements. This fragmented communication leads to confusion, missed deadlines, and poor task management.
ClassHub solves this problem by consolidating all academic deliverables into one structured system that automatically organizes, tracks, and analyzes student workload.
